# Issue #42: [M1] Auth und Datenbank-Grundlage Implementation Plan

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Implement authentication (sign up, sign in, sign out, session management, protected routes) and Drizzle ORM database migrations for PostgreSQL according to Issue #42 specifications.

**Architecture:** Framework-free domain layer (`src/domain/auth/`), infrastructure database adapters with Drizzle ORM (`src/infrastructure/db/`), application services (`src/services/auth/`), and Next.js Route Handlers (`app/api/auth/*`) plus protected page `/protected`.

**Tech Stack:** Next.js 16 (App Router), TypeScript, Drizzle ORM, PostgreSQL (`pg`), Zod, Vitest.
